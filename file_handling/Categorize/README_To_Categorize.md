# "To_Categorize.py"を使用する際の注意点<br> Cautions When Using a To_Categorize.py

---

### フォルダーのパスを指定するときの注意点/Things to keep in mind when specifying a folder path.

必ず分類したいファイルやフォルダがあるパスを指定してください。
念のためバックアップを取ることを推奨します。

Please specify the path where the files or folders you definitely want to sort are located. 
It's recommended to make a backup just in case.

---

### キーワードを入力する際の注意点

キーワードは基本的に１以上なら指定することができます。
キーワードは必ず/で区切ってください　（例：banana/apple/kiwi）
分類するファイルの名前にキーワードが含まれているかを判定しています。名前に表記されていない場合は分類されません。

You can basically specify one or more keywords.  
Make sure to separate keywords with a / (for example: banana/apple/kiwi).  
We check if the file name you want to classify contains the keywords. If it's not in the name, it won't be classified.
